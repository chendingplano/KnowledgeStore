# Overview
Artifacts are extracted/generated by doc processors (refer [1]). A sanity check is similar to
a "_test.go" file except that it uses real system, not any mocks.

## Logs

## Summary Sanity Check
Refer to [2] for summaries.

### Rule 1
All summaries must have at least one category path.

### Rule 2
`summary` must be in the same language as its input language.
The input language can be retrieved from 'kb.inputs.doc_metadata::metadata.language'

### Rule 3
`summary` must be in the following format:
```text
summary_begin
<the content of the summary>
summary_end
```

`summary_en` must be in the following format:
```text
summary_en_start
<the content of the summary>
summary_en_end
```

### Rule 3
The following must be always true:
- `summary` != `summary_en`
- `keywords` != `keywords_en`
- `lines` must be an array. Except the root-level summary, the array must not be empty. Its elements must be either 'ddd' or 'ddd-ddd', where 'ddd' is a number.
- `lines` elements must be sorted by the line numbers in ascending order
- `level` must be an positive integer
- `summary_id` must be in the format `<record_id>` + '_' + `<level>` + '_' + `<seqno>`, where `<record_id` must be identical to the field `record_id`, `<level>` must be identical to the field `level` and `<seqno>` must be a continuous sequence number with the same level, starting from 1, represented as a four-digit string, padded with 0.

### Rule 4
For each category path, the file 'summaries.txt' in the leaf directory must contain the summary ID.

### Rule 5
The following fields must be present and must not be empty:
- `create_time` must be present and must not be empty.

## Topics Sanity Check
### Rule 1
A topic must have at least one category path.

### Rule 2
For each category path, the file 'topics.txt' in the leaf directory must contain the topic ID.

## Metrics Sanity Check
### Rule 1 - `kb.metrics.metric_categories`
- `kb.metrics.metric_categories` must not be null or empty
- `kb.metrics.metric_categories_en` must not be null or empty
- If `kb.inputs.doc_metadata.metadata.language` is not English, `kb.metrics.metric_categories` must not be in English unless the category names are acronyms
- If `kb.metrics.metric_categories` is not in English, the lengths of `kb.metrics.metric_categories` and `kb.metrics.metric_categories_en` must be the same. Otherwise, `kb.metrics.metric_categories_en` is either null/empty or identical to `kb.metrics.metric_categories`

### Rule 2
For each metric category in `kb.metrics.metric_categories`, a corresponding record in `kb.category_instance`
must exist:
- `SELECT category_id FROM kb.category_instance.input_record_id = input_record_id`
- Convert all category ids to category_names
- `category_names` must be the same as `kb.metric_categories`
```
