## Page Design

Menu Name: Artifact Web

Page Design:
```text
┌───────────────────────────────────-──────────────────-─────────┐
│  Menu         |           Canves           | Information Panel │
|───────────────────────────────-──--────-──────-────────────────|   
│  ...          |                            |                   |
│  Artifact Web |                            |                   |
│  ...          |                            |                   |
└─────────────────-──--──────────────────────────────────────────┘
```
- The page has a canvas in the middle and a Information Panel to the right
- There is a slider between the Menu Panel and Canvas, and Canvas and Information panel.
  Use these sliders to adjust the width of Menu Panel and Information Panel
- The Canvas shows a horizontal tree (from EChart).
