# Overview - Term Ontology Bean
**Term Ontology Bean** defines a term.

## Attributes
| Attribute Name | Data Type | Mandatory | Explanation |
|----------------|-----------|-----------|-------------|
| name | string | required | A name that uniquely identifies a term ontology bean |
| description | text | required | Description of the term |
| category | Category Ontology Bean | optional | The term's category |
| keywords | an array of keyword ontology beans | optional | The term's keywords |
