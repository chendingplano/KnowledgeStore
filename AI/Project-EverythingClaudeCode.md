## Context Cost Analysis

At session start, Code Assistant injects a list of all available skills (name + description frontmatter) into the system context, and it stays there for every turn. 
After installing ECC, the system has ~250 skills. If the average size of one skill is 100 bytes, this results in 250 x ~100 bytes ≈ 25 KB, a reasonable order-of-magnitude estimate. In tokens that's roughly 6–8K tokens of fixed overhead.

Descriptions in ecc are, however, often longer than 100 bytes (many are 200–400 chars), so real cost is likely 2–4× of the above estimate — call it 15–30K tokens.
This block is prompt-cached, so you pay the full token cost once per 5-minute window, then cached reads after that (~10% the cost) (at least true for Claude Code). It still consumes context window space though.

The skill body is only loaded when you actually invoke it via the Skill tool — that part is on-demand.
So: fixed ~15–30K tokens of context budget burned every session just to know what's available. With 250 skills it's worth being selective — ecc ships profile-based installs for exactly this reason.
