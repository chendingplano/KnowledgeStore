# Commands

| Command | Explanations |
|:--------|:-------------|
| \l | List databases |
| \c <dbname> | Use <dbname> |
| \conninfo | Show current connection info |
| \dt | List tables |
| \d tablename | Describe table |
| \d+ | More detailed info |
| \dn | List schemas |
| \du | List users/roles |
| \x | Toggle expanded display (great for wide tables) |
| \i file.sql | Run SQL file |
| \o output.txt | Send query output to file |
| \o | Reset output to std out |
