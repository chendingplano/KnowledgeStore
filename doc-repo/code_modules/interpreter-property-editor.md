# 1. Purposes

This document defines the rules in creating/modifying the property editors that are shown in
the Properties panel of the WPI Editor.

# 2. Rules

## 2.1 Property Editor Structure
A property editor is constructed as:
- title line
- property groups (a list of round rectangles working as a folder)
