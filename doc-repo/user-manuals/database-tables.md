# Database Tables — SemOS Ontology & Keyword Lexicon

**Date:** 2026-08-10
**Audience:** ChenWeb engineers and operators
**Scope:** Every database table the SemOS ontology framework (ADR `2026072901`) creates, alters, or references, grouped by the phase that introduces them
**Applies to:** ChenWeb `kb.*` schema (Postgres)

---

## 1. Purpose

This document enumerates every database table the SemOS ontology framework creates or alters,
grouped by the phase that introduces them. For each table it gives a description, the key columns,
the ADR decision or layer it belongs to, and its authoring or generation surface. Tables that predate
the ADR and are only referenced (not created or altered) are listed separately at the end.

**History:** this content was originally Appendix C of
`KnowledgeStore/doc-repo/adrs/202607/2026072901-adr-ontology-platform-and-adaptive-pipeline.md`. It
was moved here on 2026-08-10 because a living table inventory belongs in an operator-facing reference
that gets updated as tables are added, not inside an architecture-decision record whose job is to
record a decision and its history — the ADR had already drifted (§C.4's keyword-lexicon governance
tables were never enumerated, only gestured at with a footnote) by the time of the move. This document
is expected to be kept current; the ADR is not.

If this document and the live schema disagree, the live schema (and the migration files under
`ChenWeb/project_migrations/`) are the source of truth.
