This is a Typst template for "Document Review Report".
The report should contain the following chapters:
- Basic Information
- Review Results
  - Summarize the review, the aspects reviewed and the statistics about the review
  - One section per aspect: 
    - One sub-sectoin per review result
    - One sub-sectoin per review result
      - Related source lines from the document, add five lines before and five lines after the source lines, using different colors
      - Errors
      - Explanation of the errors
      - Recommended correction
    ...
    - Overall assessment of the document quality in this aspect
    - Main problem analysis in this aspect
    - Guidelines and recommendations to avoid the problems in the future
- Grounding References
  List all the grounding documents
- Supporting References
  List all the documents based on which the document review is built.
  This comes from configurations.
