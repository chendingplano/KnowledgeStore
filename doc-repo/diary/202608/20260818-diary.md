### 1.2 Findings
- GPT text-embedding-3-large is expansive, but the model is trained so that
  any prefix of the full embedding vector retains useful semantic structure.
  This means you can truncate a 3072-dimensional vector to 512 dimensions
  and still retain about 94% of its retrieval quality, at a fractino of the 
  storage cost.
- BGE-M3 from BAAI runs locally, multilingual and it supports three retrieval
  modes from a single model: sparse (BM25-style), and ColBERT late interaction.
  The hybrid of dense + sparse consistently outperforms pure dense retrieval
  by 5-12 points on technical corpora.
- Semantic Chunking with Sentence Similarity: sentence-wise, until the similarity
  drops to a threshold; cut the current chunk and start a new one. This alone adds
  about 6% in the benchmark.
