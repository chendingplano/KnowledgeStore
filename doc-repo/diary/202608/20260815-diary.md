### Database Utilities

Use `databaseutil` package for consistent table management:

```go
import "github.com/chendingplano/shared/go/api/databaseutil"

// Table creation and management
databaseutil.ExecuteStatement(db, createTableStmt)
```

### Email Service

The tax/Mirai project uses **Resend** for transactional emails via the `email` package:

**Path:** `tax/server/internal/email/`

**Configuration:** Requires `RESEND_API_KEY` in `.env`
