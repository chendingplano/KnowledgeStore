# Requirements for Tools

- Document ID: `2026100501-rqmt`
- Status: Proposed
- Date: 2026-10-05
- Audience: Product owners, subject-matter experts, designers, developers, testers, and operators

## 1. Purpose

This document lists and discusses the tools SemOS provide. These tools are mainly
designed for agents.

## 2. Tools
### 2.1 list_documents
List documents in the corpus/knowledge store.

### 2.2 get_document_outline

Given a document id (normally `kb.inputs.id`), it returns the outline of the document,
or the hierarchical outline/tree of a document.

### 2.3 read_chunks

Read exact chunks by page, section path, chunk ID/type, or range.

### 2.4 grep_chunks

Literal or regex search *within one document*

### 2.5 hybrid_search
Broad retrieval/search across published documents

### 2.6 async_parse_url
Ingest/parse a document from a URL.

### 2.7 async_parse_file
Ingest/parse a local file

### 2.8 async_get_job_status
Check asynchronous parsing status/results

### 2.9 delete_document
Soft-delete/archive a document.

### 2.10 retrieve_artifacts
It retrieves artifacts. Available artifacts are:
- metric
- provision
- product
- semantic projection
- workflow
- ...

*Inputs*
- artifact_type (one and only one, mandatory)
- keywords
- labels
- categories
- description
- product
