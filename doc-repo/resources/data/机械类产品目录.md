这是一份机械类产品目录的表格，表头各字段含义如下：

| 字段名 | 含义 |
|---|---|
| **code_class_large** | 大类代码。产品分类中最高层级的代码，如 `35` 代表“锅炉及辅助设备”这一大类。 |
| **code_class_medium** | 中类代码。大类下的细分，如 `01` 表示大类 35 下的第一个中类。 |
| **code_class_small** | 小类代码。中类下的进一步细分，如 `01` 表示中类 01 下的第一个小类。 |
| **code_group** | 组代码。小类下的分组，如 `01`、`02`、`03` 表示小类下的不同产品组。 |
| **child_code_group** | 子组代码。组下的更细分组，如 `00` 通常表示该组下没有进一步细分或为默认子组。 |
| **product_name** | 产品名称。具体产品的名称，如“超临界（超超临界）电站锅炉”。 |
| **note** | 备注。对该产品的补充说明，如定义、范围、技术参数等。 |
| **industry_code** | 行业代码。该产品所属的行业分类代码，如 `3511` 对应“锅炉及原动设备制造”相关行业。 |
| **cpc** | 中央产品分类代码（Central Product Classification）。联合国统计司制定的产品分类标准代码，用于国际比较，如 `42320` 可能对应“蒸汽锅炉”类产品。 |
| **entry_no** | 旧版目录条目编号。该产品在旧版产品目录中的序号，如 `17673`。 |
| **entry_no_new** | 新版目录条目编号。该产品在新版产品目录中的序号，如 `17673`（此例中与旧版相同）。 |

### 层级关系说明

表格的代码字段构成一个**层级分类体系**：

```
大类 (code_class_large)
  └─ 中类 (code_class_medium)
       └─ 小类 (code_class_small)
            └─ 组 (code_group)
                 └─ 子组 (child_code_group)
```

例如第一行：
- 大类 `35` → 中类 `01` → 产品“锅炉及辅助设备”
- 第三行：大类 `35` → 中类 `01` → 小类 `01` → 产品“电站锅炉”
- 第四行：大类 `35` → 中类 `01` → 小类 `01` → 组 `01` → 子组 `00` → 产品“超临界（超超临界）电站锅炉”

### 其他字段说明

- **industry_code**：用于关联国民经济行业分类，便于统计和行业管理。
- **cpc**：用于国际产品分类对比，便于国际贸易和统计。
- **entry_no / entry_no_new**：用于版本管理，方便追踪产品在目录修订中的位置变化。

简单说，这是一张**多层级产品分类目录表**，用于对机械类产品进行系统化编码、统计、管理和检索。
